# LVA-NÖ Quiz

Interaktives Quizsystem für Veranstaltungen der Landesverkehrsabteilung Niederösterreich.

## Funktionen

- Teilnehmerregistrierung
- Multiple-Choice-Fragen
- Schätzfragen mit Toleranzbewertung
- Live-Rangliste
- Statistikauswertung
- Dienststellenvergleich
- Feedback-Umfragen nach dem Quiz
- Auswertung der Umfrageergebnisse

## Technik

- HTML
- CSS
- JavaScript
- Supabase (Datenbank und Authentifizierung)

## Datenbank

Verwendete Tabellen:

- Teilnehmer
- Fragen
- Antworten
- Umfragen
- Bewertungen
